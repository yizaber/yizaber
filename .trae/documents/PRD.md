# 像素风机甲对战游戏 - 产品需求文档

## 1. 产品概述

### 1.1 项目简介
一款复古像素风格的双人机甲对战小游戏，玩家控制机甲在竞技场中与对手进行战斗，支持移动、攻击、防御等操作，采用血条机制判定胜负。

### 1.2 目标用户
- 喜爱复古像素风格游戏的玩家
- 喜欢格斗对战类游戏的轻度玩家
- 寻求短时娱乐体验的用户

### 1.3 核心价值
- 简单易上手的操作体验
- 复古像素风格的视觉享受
- 紧张刺激的对战体验

---

## 2. 核心玩法设计

### 2.1 基本规则
- **对战模式**: 1v1 双人对战
- **胜利条件**: 将对手血量降至0
- **时间限制**: 单局限时99秒
- **平局规则**: 时间结束时血量高者胜

### 2.2 操作方式

#### 玩家1 (左侧机甲 - 蓝色)
| 按键 | 操作 |
|------|------|
| A | 向左移动 |
| D | 向右移动 |
| W | 跳跃 |
| S | 防御 |
| 空格 | 普通攻击 |

#### 玩家2 (右侧机甲 - 红色)
| 按键 | 操作 |
|------|------|
| ← | 向左移动 |
| → | 向右移动 |
| ↑ | 跳跃 |
| ↓ | 防御 |
| Enter | 普通攻击 |

### 2.3 战斗系统

#### 基础属性
| 属性 | 默认值 | 说明 |
|------|--------|------|
| 生命值 | 100 | 归零时战败 |
| 攻击力 | 10 | 普通攻击伤害 |
| 移动速度 | 5 | 像素/帧 |
| 跳跃力 | 15 | 初始向上速度 |
| 防御减伤 | 50% | 防御时受到伤害减免 |

#### 攻击类型
1. **普通攻击**: 近战拳击，范围小，伤害10点，冷却0.5秒
2. **跳跃攻击**: 空中向下攻击，伤害15点，有击退效果
3. **连击**: 连续命中3次触发，第三次伤害翻倍

#### 防御机制
- 按下防御键进入防御姿态
- 防御姿态无法移动和攻击
- 受到的伤害减少50%
- 防御有耐久度，连续受击会破防

### 2.4 场景元素

#### 战斗场地
- 尺寸: 800x600像素
- 地面: 中央平台，宽600像素
- 边缘: 两侧有边界墙
- 背景: 像素城市剪影

#### 危险区域
- 掉出场地底部视为坠落
- 坠落扣除30点生命值
- 3秒后重生在场地中央

## 3. 视觉设计

### 3.1 整体风格
- **风格定位**: 复古8-bit像素风格
- **色彩方案**: 高对比度配色，霓虹色调
- **画面比例**: 4:3复古比例

### 3.2 色彩系统

#### 主色调
| 颜色 | 色值 | 用途 |
|------|------|------|
| 深蓝 | #1a1b3a | 背景主色 |
| 霓虹蓝 | #00d4ff | 玩家1主题色 |
| 霓虹红 | #ff3366 | 玩家2主题色 |
| 金黄 | #ffd700 | UI高亮、金币 |
| 纯白 | #ffffff | 文字、特效 |

#### 辅助色
| 颜色 | 色值 | 用途 |
|------|------|------|
| 深灰 | #2d2d3a | 面板背景 |
| 中灰 | #5a5a6e | 次要文字 |
| 浅灰 | #8a8a9e | 禁用状态 |
| 绿色 | #00ff88 | 治疗、正面效果 |
| 橙色 | #ff8800 | 警告、连击 |

### 3.3 机甲设计

#### 机甲A型 (玩家1 - 蓝色)
- **造型**: 人形机甲，流线型设计
- **主色**: 深蓝+天蓝渐变
- **特征**: 单眼传感器(蓝色)，背部推进器
- **尺寸**: 48x64像素
- **动画帧**: 待机8帧、行走8帧、攻击6帧、跳跃4帧、防御4帧、受击4帧

#### 机甲B型 (玩家2 - 红色)
- **造型**: 重装机甲，方正厚重设计
- **主色**: 暗红+橙红渐变
- **特征**: 双眼传感器(红色)，肩部装甲
- **尺寸**: 52x64像素
- **动画帧**: 同机甲A型

### 3.4 场景设计

#### 战斗背景
- **远景**: 像素城市剪影，霓虹灯光
- **中景**: 工业管道、起重机
- **近景**: 战斗平台、能量屏障
- **特效**: 粒子火花、蒸汽喷发

#### 平台设计
- **主平台**: 金属质感，带霓虹边缘
- **尺寸**: 600x80像素
- **细节**: 铆钉、接缝、磨损痕迹

### 3.5 UI设计

#### 血条设计
- **样式**: 霓虹边框+渐变填充
- **尺寸**: 200x20像素
- **颜色**: 蓝/红主题色
- **特效**: 低血量闪烁警告

#### 能量/技能条
- **位置**: 血条下方
- **样式**: 分段式能量格
- **用途**: 显示技能冷却、能量积累

#### 战斗信息
- **位置**: 屏幕中央上方
- **内容**: 回合数、倒计时、连击数
- **样式**: 霓虹数字+像素字体

## 5. 动画规范

### 5.1 动画帧率
- **游戏逻辑**: 60 FPS
- **动画播放**: 12帧/秒(像素风格)
- **特效动画**: 30帧/秒

### 5.2 动画列表

#### 机甲A型/B型通用
| 动画 | 帧数 | 循环 | 说明 |
|------|------|------|------|
| 待机 | 8 | 是 | 轻微呼吸起伏 |
| 行走 | 8 | 是 | 左右交替迈步 |
| 跑步 | 6 | 是 | 快速移动，后仰姿态 |
| 跳跃 | 4 | 否 | 起跳→空中→落地 |
| 普通攻击 | 6 | 否 | 蓄力→出拳→收回 |
| 防御 | 4 | 是 | 格挡姿态，手臂交叉 |
| 受击 | 4 | 否 | 后仰，闪烁效果 |
| 战败 | 8 | 否 | 跪地→倒地→消失 |
| 胜利 | 6 | 否 | 举拳庆祝动作 |

#### 特效动画
| 动画 | 帧数 | 用途 |
|------|------|------|
| 攻击特效 | 8 | 出拳气流 |
| 受击特效 | 6 | 火花四溅 |
| 防御特效 | 4 | 护盾波纹 |
| 坠落特效 | 10 | 烟雾+震动 |
| 重生特效 | 8 | 传送光圈 |

## 6. 技术需求

### 6.1 平台要求
- **Web端**: 现代浏览器(Chrome/Firefox/Safari/Edge)
- **分辨率**: 支持800x600及以上，自适应缩放
- **输入**: 键盘支持(双人对战)

### 6.2 性能要求
- **目标帧率**: 60 FPS
- **加载时间**: 首屏<3秒
- **内存占用**: <200MB
